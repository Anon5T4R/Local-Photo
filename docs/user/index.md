Local Photo is a photo library and raw developer that runs on your own computer. It is an open-source alternative to Adobe Lightroom, written in Rust, and part of the Craft App Suite from the ArtCraft team.

You import photos, sort them with ratings, flags and albums, and edit them without touching the originals. It reads raw files from Canon, Sony, Nikon, Fujifilm, Panasonic, Leica, Pentax and Olympus cameras, and DNG. There is no account, no cloud, no telemetry and no subscription. It runs on Windows, macOS and Linux. Local Photo is in alpha, so expect rough edges.

## Get help

Ask in [Discord](https://discord.gg/artcraft) or open an issue in the [issue tracker](https://github.com/Anon5T4R/Local-Photo/issues). Say which system and camera you use, and your Local Photo version (**Help** > **About Local Photo**; on macOS, **Local Photo** > **About Local Photo**).
